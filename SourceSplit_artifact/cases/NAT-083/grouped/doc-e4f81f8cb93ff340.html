Outlet Flow Measurement

Collection handoff

Outlet-flow work needs safe access, a stable collection arrangement and a stated operating condition.

The contractor memo should identify these preparations before the visit.

Leave instrument and unit references with the collection sheet so the observations remain interpretable. Plan vessel access and drainage before opening the fitting for collection.
