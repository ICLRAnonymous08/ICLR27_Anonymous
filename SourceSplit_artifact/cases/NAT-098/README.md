# NAT-098: Paperboard water absorption

**Domain:** Materials/packaging

## Public question

Determine whether the following proposition is true.
Entity: Recycled linerboard RB-9
Metric: surface water absorption
Condition: specified side, conditioned sheet, 60-second exposure and 0.10 m² clamp
Time window: one fresh sheet specimen per acquisition
Target population: valid exposed specimens from the locked paper lot
Aggregation: mass gain / exposed area
Validity rule: use the area of the actual clamp and preserve tare/dry/wet masses
Comparison: strict > 40.0 g/m²
