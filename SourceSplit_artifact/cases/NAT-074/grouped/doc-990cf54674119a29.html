P-6 Short-Start Runtime Runbook

Startup-only configuration

The P-6 short-start configuration launches the worker, checks initialisation and exits before warm-up completes. It does not enter a steady workload window.

Inspect exit status, process identifiers and configuration loading in that order. Keep a failed initialisation separate from a normal exit requested by the short-start wrapper.

  • File the startup log with the short-start wrapper settings after checking the requested exit disposition.
