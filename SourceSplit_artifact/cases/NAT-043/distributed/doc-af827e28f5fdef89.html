Converting Tape Measurements to Water-Level Elevations

The field calculation note shows how a tape reading is carried from the well sheet into an elevation entry.

Worksheet steps

1. Read depth
Use the wetted graduation at the permanent measuring point
2. Apply tape correction
Use the active equipment check only when a correction is documented
3. Subtract from MP elevation
Keep all values in the same length unit
4. Record datum
Write the vertical datum beside the elevation

Review prompts

  • Are both dates tied to the same measuring-point definition?
  • Were the water levels stable before each reading?
  • Do the field sheet and database carry the same well identifier?
