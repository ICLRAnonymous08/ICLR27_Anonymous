Aquifer Monitoring Network and GW-11 Setting

GW-11 is one station in a monitoring network designed to follow groundwater conditions across the mapped aquifer.

Network context

Hydrogeologic unit
Unconfined sand and gravel monitoring interval
Land setting
Mixed agricultural and low-density residential use
Nearby network role
Intermediate location between recharge and discharge areas

Profile maintenance

The network profile is revised when well construction, pumping influences or land access change. Hydrographs and measurement records are maintained separately from this descriptive profile.
