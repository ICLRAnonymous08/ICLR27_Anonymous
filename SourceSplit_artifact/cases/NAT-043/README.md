# NAT-043: Groundwater depth change

**Domain:** Environmental monitoring

## Public question

Determine whether the following proposition is true.
Entity: Monitoring well GW-11
Metric: water-level elevation change
Condition: same well and common surveyed vertical datum
Time window: two locked measurement dates
Target population: manual tape measurements after stabilization on both dates
Aggregation: later water elevation minus earlier water elevation
Validity rule: apply the same measuring-point correction and datum on both dates
Comparison: strict > 0.5 m
