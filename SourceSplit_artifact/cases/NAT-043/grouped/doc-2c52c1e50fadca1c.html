GW-11 Transducer Installation and Configuration

This card records the hardware and logging choices used for the pressure transducer installed at GW-11.

Installation configuration

Suspension
Vented cable secured below the casing cap
Logging interval
Routine network interval set in the field program
Barometric handling
Vented reference; desiccant condition checked at visits
Clock
Logger set to the network time convention

Commissioning checks

  • Compare one transducer reading with a manual tape observation.
  • Confirm cable depth and strain relief.
  • Verify station name and units in the downloaded header.
