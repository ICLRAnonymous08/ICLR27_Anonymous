Readiness review: VG-4 clears the completion-rate reference

Line-readiness check

Cell
VG-4 vacuum handling cell
Measure
Complete pick-transfer-place success proportion
Review context
Run-entry comparison for commissioning handover
Comparison status
Reported rate above the 92% reference; not strictly below

Before using the status

  • Match the rigid workpiece set and initial-pose distribution to the commissioning recipe.
  • Check that vacuum setting, transfer path and motion speed remain as specified.
  • Use the final placement tolerance that defines completion for this handling sequence.
  • Identify the locked 50–75-trial session associated with the comparison before handing it over.

During operation

Keep started trials in the total. When reviewing completion, retain both aborted starts and transit drops instead of restricting the population to movements that reached their final destination. Pickup alone is not the end of the defined movement through to in-tolerance placement. Use the comparison to close the readiness item, not as a substitute for safety approval.
