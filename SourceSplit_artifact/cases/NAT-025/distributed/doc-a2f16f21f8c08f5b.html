Setting up a complete-transfer measurement

Before a vacuum-handling study, verify event-clock alignment, final-position sensing and the rule used to retain aborted trials. The record form should separate initiated trials, successful pick-ups, in-transit losses and placements inside tolerance.

Required setup checks

  • Confirm the selected recipe and workpiece family.
  • Verify the vacuum channel and final-position sensor.
  • Start the event record before the first initiated trial.
  • Document exclusions before reviewing any result.

Before releasing the form, the technician signs the clock check, final-position sensor check and denominator rule. Blank run rows are then issued with the work order.
