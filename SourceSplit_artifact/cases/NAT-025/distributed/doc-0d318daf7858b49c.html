VG-4 exception 17 closed after completion-rate review

Exception 17 concerns the completion-rate comparison for the VG-4 vacuum handling cell at commissioning handover. Review of the run entry closes this comparison item for the locked handling recipe.

Inspection boundary

Workpieces
Rigid workpiece set with the original initial-pose distribution
Motion
Unchanged transfer path and speed
Grip
Locked vacuum setting
Placement
Original final-position tolerance
Session
One locked commissioning acquisition of 50–75 initiated trials

Completion rule

The completion measure includes pickup, uninterrupted transfer and final placement within the specified tolerance. A started trial remains part of the population even when it ends before placement.

Decision matrix

Evidence for closure
Reported completion rate: 4 percentage points above the comparison reference
Strictly below reference?
No
Disposition
Comparison item closed for handover

Retain the recipe identification at handover. Closing the completion-rate comparison does not certify the cell for other duties or authorize applying this disposition to a changed handling recipe.
