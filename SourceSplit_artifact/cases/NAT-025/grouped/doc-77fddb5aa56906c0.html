Retrofit closeout records VG-4 above the reference

Mechanical retrofit closeout for VG-4 leaves the handling recipe as an essential part of maintenance handover. Technicians need that recipe to interpret the completion comparison when the cell returns to routine use. The comparison concerns a finished pick-transfer-place sequence, not a statement about every function of the installation.

Carry forward the recipe

Keep the rigid workpiece set identifiable alongside the distribution of initial pickup poses used during commissioning. The vacuum setting belongs to the same configuration as the selected path and movement speed. Final placement tolerance completes this description by defining where successful handling must end. A technician reviewing a subsequent adjustment should be able to distinguish that adjustment from the retained configuration.

Closeout annotation

The reported completion proportion is above the 92% reference for the locked commissioning session. It does not fall strictly below the reference used for this engineering comparison. The session boundary is one acquisition of 50–75 initiated trials under the unchanged recipe. In this measure, successful handling includes pickup, uninterrupted transfer and final placement inside tolerance.

Using the closeout after service

Aborted starts remain part of the population. Transit drops likewise remain among initiated attempts when the percentage is calculated for a session. If service changes the recipe, identify the changed setting before applying the existing completion comparison. A change to the allowed finish position, for example, changes the condition defining a completed move even if the transfer path stays the same. Keep that distinction in maintenance handover. The reference addresses handling performance and should not be used as a safety or certification limit.
