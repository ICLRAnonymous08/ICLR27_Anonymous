What the unloaded VG-4 checkout can establish

An unloaded checkout is useful for confirming axis motion, path clearance, interlocks and cycle sequencing before workpieces enter the cell. It can also expose cable drag or an unexpected dwell.

Boundary

An unloaded checkout is logged as setup work, with axis motion, interlock response and clearance observations entered before workpiece trials begin.

Record the checkout as a setup activity and keep it separate from later workpiece trials.
