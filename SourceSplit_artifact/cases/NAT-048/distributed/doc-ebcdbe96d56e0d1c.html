Full-Charge Preparation for Earbud Playback Tests

Earbuds are prepared from a known full-charge state before a controlled playback run begins.

Preparation checklist

  • Clean the charging contacts and seat both earbuds in the case.
  • Charge the case and earbuds until all expected indicators settle.
  • Confirm firmware and paired-device software versions.
  • Disable unrelated notifications and automatic ear detection if the protocol requires it.
  • Load the specified playlist and verify the volume control path.

Start record

The technician records the removal time from the case and confirms that both channels begin playback.
