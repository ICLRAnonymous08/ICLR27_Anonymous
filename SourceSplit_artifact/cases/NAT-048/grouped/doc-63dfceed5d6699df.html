ANC and Listening-Mode Reference

Listening modes

ANC
Active processing intended to reduce external sound
Transparency
External microphones mixed into playback
Off
Neither ANC nor transparency processing selected
Adaptive
Automatic adjustment where supported by firmware

Recording a setting

Support and test records name the mode shown by the host device and note any spatial-audio or automatic-switching feature that is active.
