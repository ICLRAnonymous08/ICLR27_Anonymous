EB-48 Power-Management and Firmware Compatibility

This note lists firmware and host-device combinations supported by the EB-48 power-management features.

Compatibility

Earbud firmware
Current supported production branch
Mobile software
Versions that expose battery and listening-mode status
Bluetooth audio
Supported profiles and negotiated codec behavior
Charging case
Matching case firmware required for coordinated sleep and wake

Configuration checks

  • Update both earbuds as a pair.
  • Restart the host device after a major Bluetooth stack update.
  • Confirm that battery optimization does not suspend the playback application.
